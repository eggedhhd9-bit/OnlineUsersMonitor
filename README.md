# پاک‌یاب DNS

ابزار ویندوزی برای پیدا کردن DNSهای قابل‌دسترس و مقایسهٔ پایداری و سرعت پاسخ آن‌ها.

## چه کاری می‌کند؟

- DNSهای تنظیم‌شده روی کارت‌های شبکهٔ ویندوز را پیدا می‌کند.
- آن‌ها را با چند DNS عمومی مقایسه می‌کند.
- سه دامنهٔ عمومی (`example.com`، `iana.org` و `cloudflare.com`) را با درخواست DNS/UDP آزمایش می‌کند.
- نرخ پاسخ معتبر و میانهٔ زمان پاسخ را نشان می‌دهد و بهترین پاسخ‌گوها را بالاتر می‌آورد.
- هیچ تنظیمی را در ویندوز تغییر نمی‌دهد.

برنامه بررسی فنیِ دسترسی و پاسخ‌گویی است؛ نتیجه، گواه نبود سانسور یا تضمین امنیت نیست. درخواست‌های آزمایش‌شده به DNSهایی که مقایسه می‌شوند ارسال می‌شوند.

## اجرا روی Windows 10/11

فایل `DNSCleanFinder.exe` را اجرا کنید. برای ساخت محلی از سورس، Python 3.12 را نصب و `build-windows.bat` را اجرا کنید.

## DNSهای مقایسه‌ای

- Cloudflare: `1.1.1.1` (معمولی) و `1.1.1.2` (مسدودسازی بدافزار)
- Google Public DNS: `8.8.8.8`
- Quad9 Secure: `9.9.9.9` (مسدودسازی دامنه‌های مخرب)

بیلد ویندوز با push به `main` در GitHub Actions ساخته می‌شود و در بخش Artifacts همان اجرا قرار می‌گیرد.
