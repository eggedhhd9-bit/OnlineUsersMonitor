# سامانهٔ حضور و غیاب پرسنل

برنامهٔ ویندوزی برای ثبت‌نام کارکنان، ثبت خودکار تاریخ و ساعت ورود و خروج، مشاهدهٔ وضعیت حضور و گرفتن گزارش CSV.

## امکانات

- ثبت کارمند با کد پرسنلی، نام و واحد یا سمت
- ثبت ورود و خروج با زمان محلی رایانه
- جلوگیری از ورود دوباره تا زمان ثبت خروج قبلی
- نمایش کارکنان حاضر و خارج
- گزارش روزانه یا همهٔ سوابق، همراه مدت حضور
- خروجی CSV سازگار با Excel

برنامه برای استفاده روی یک رایانه طراحی شده است. اطلاعات در پایگاه SQLite در `%LOCALAPPDATA%\StaffAttendance\attendance.sqlite3` ذخیره می‌شوند و خودکار بین چند رایانه همگام نمی‌شوند. ساعت ثبت بر اساس ساعت ویندوز است.

## اجرا در Windows 10/11

از GitHub Actions فایل `StaffAttendance-windows` را در بخش Artifacts دانلود کنید، ZIP را باز کنید و `StaffAttendance.exe` را اجرا کنید. برای ساخت محلی از سورس، Python 3.12 را نصب و `build-windows.bat` را اجرا کنید.
